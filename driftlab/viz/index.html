Welcome to the driftlab dashboard

driftlab puts agents in jobs whose rules keep changing and measures how they cope, against ground truth the agents never see. Everything here is read from the run logs. You can watch agents work live, replay finished runs, compare agents across experiments, and browse the research. Every panel explains itself under its heading.

New here? Start with the core concepts

World

A job at a made-up company: an intake desk, order-form data entry, an inventory buyer, a developer. Hidden, seeded rules decide what counts as correct. The agent is never told it is in an experiment. It just works the job.

Agent

Anything that answers text with text. It gets an observation, replies with an action, and hears the outcome. An LLM with a memory strategy, a simple lookup baseline, and an external coding agent such as Claude Code all play under the same contract and the same measurements.

Drift

How the world changes. A real change moves what is correct: a rule flips, demand jumps. A cosmetic change moves only the wording, so reacting to it is a mistake. A self-caused change happens because of the agent's own behavior, and nothing announces it.

Experiment

A protocol laid over a world: when and how the world changes, what warnings or probes appear, and what gets measured. There are fifteen, each registered with its design, settings and a version (see Research). The same experiment can run on any world that supports what it needs.

Regime

One condition inside an experiment, such as cosmetic vs real change, or a change rate of 0, 4 or 12. Each condition runs several times with different seeds (the world's random draw), and every agent gets the same seeds, so everyone faces the exact same worlds. That is what makes the comparisons fair.

Run

One agent playing one condition for a fixed number of steps. Each run is one entry in the Runs list and one log file. The log records every step next to the hidden ground truth the agent never saw, and everything on this dashboard is computed from those logs.

Profile & score

After runs finish, their logs are measured into a standard profile: how fast the agent noticed and recovered from each change, how much stuck, whether its confidence was honest, and what it cost. These normalize into four dimensions from 0 to 1; the three capability dimensions average into the driftlab score, with efficiency (cost, discipline) reported beside it rather than blended in. The profile is the result; the score just ranks.

Hypothesis

A claim that spans experiments (H001 to H005), kept in the research log with a status and an evidence table that grows with every run, contradictions included. Experiments produce numbers; hypotheses are where the numbers become knowledge.
